Readable PL/SQL starts with knowing the format.

Oracle PL/SQL Unwrapper is a free Java library and command-line tool for Oracle wrap format V2. It recognizes V1, but does not unwrap it. This resource hub explains the supported path and where to go when a case needs more.

One project, two different paths

Start with the format and the scope of the work. The open-source project covers V2. V1, managed bulk recovery, re-wrapping, and difficult cases are separate professional services.

Free · self-service

Oracle wrap V2

Use the Java library or CLI for wrapped PL/SQL from Oracle 10g through 26ai+. Native releases are available for Linux x64, Windows x64, and macOS arm64/x64.

Recognized · not restored

Oracle wrap V1

V1 covers Oracle 7.2–9.2. The public project can recognize V1 and reports that it is not supported for unwrapping. It does not attempt a V1 restore.

Scope-dependent

Bulk and complex work

Set expectations

Readable logic, not the original file

The V2 format does not retain the original PL/SQL version. Recovery can restore program logic and identifiers, but comments and original formatting are usually lost. The result should not be treated as a byte-for-byte reconstruction.

The Maven Central artifact is com.github.sftwnd:oracle-plsql-unwrapper:1.0.0.

About the browser tool

The unwrap backend is currently local-only and is not offered as a public online service. For the free V2 path, use the project repository, releases, library, or CLI.

A known upgrade concern

Oracle 23ai/26ai and PLS-01918

By default, Oracle 23ai/26ai reports PLS-01918 for code wrapped with wrap 9.2 or older. That is not a universal claim for every database or configuration. If the source is missing, identify the wrap format before choosing a recovery path.

Do not send source code with an initial inquiry. For commercial recovery, the customer must demonstrate lawful rights to the code. Written confirmation and an NDA are required before work begins. Oracle internal packages and third-party code must not be submitted without authorization.
