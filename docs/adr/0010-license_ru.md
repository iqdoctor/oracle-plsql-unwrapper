# 0010. Лицензия: BSD-3-Clause, закрытая для контрибуций

[English version](0010-license.md)

## Контекст

Этот проект содержит контракт wrapped-формата, формат V2 и unwrapper. Формат — отдельный модуль, реализующий контракт, и
такой модуль может быть закрытым: формат V1 именно такой. Приложение встраивает unwrapper и его форматы в свой продукт.
Код пишет один автор, у которого все права на него.

## Решение

- Лицензия — BSD 3-Clause License (`BSD-3-Clause`), полный текст в `LICENSE`; в родительском `pom.xml` она указана в
  `<licenses>`.
- Каждый jar содержит текст лицензии своего проекта в `META-INF/LICENSE`, а дистрибутив — в своём корне.
- Проект не принимает стороннего кода. README об этом сообщает, а pull request и патчи извне закрываются без
  рассмотрения. Issue с сообщениями об ошибках и вопросами остаются открытыми.
- Каждый файл `.java` начинается со строки `// SPDX-License-Identifier: BSD-3-Clause`, и тот же идентификатор указан в
  `pom.xml`, чтобы лицензию можно было прочитать из файла, взятого отдельно от репозитория, и сканерами лицензий.

## Обоснование

- Закрытый модуль может реализовать SPI и работать с unwrapper, только если лицензия SPI и unwrapper на него не
  распространяется. Копилефт-лицензия распространялась бы.
- Разрешительная лицензия не ставит условий продукту, встраивающему библиотеку, поэтому вторая лицензия не нужна.
- Третье условие не даёт использовать имя правообладателя для продвижения производных продуктов.
- Закрытие контрибуций сохраняет права у одного владельца без соглашения с контрибьюторами, которое требует процесса и
  подписей всех, кто вносит код.
- Форк остаётся разрешён: лицензия даёт это право всем.

## Альтернативы

- **AGPL-3.0 с коммерческой лицензией.** Код продукта на основе библиотеки пришлось бы открывать либо заключать отдельное
  соглашение, а закрытый формат не сочетался бы с SPI.
- **MIT.** Тоже разрешительная, но без условия об имени правообладателя.
- **Apache-2.0.** Тоже разрешительная, с патентным грантом и дополнительными условиями для изменённых файлов; проекту они
  не нужны.

## Последствия

- Продукт, использующий библиотеку, с изменениями или без них, может оставаться закрытым, если сохраняет уведомление об
  авторских правах и текст лицензии.
- Лицензия каждой зависимости должна это допускать. У библиотеки нет сторонних зависимостей, кроме тестовых.
- Взять в репозиторий чужой код можно только под лицензией, которая допускает его использование на этих условиях.
- У закрытого модуля формата V1 и проекта `oracle-plsql-unwrapper-pro` свои условия, и эта лицензия их не охватывает.
